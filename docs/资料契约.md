# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## shipments

客户票货及结构，不描述运输时效承诺。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 票货 |
| `customer` | string | 客户 |
| `category` | string | 货类 |
| `weight_kg` | number | 实重 |
| `chargeable_kg` | number | 计费重 |
| `revenue_minor` | integer | 原币收入 |
| `currency` | string | 币种 |
| `received_minor` | integer | 回款 |

## segments

实际共同运段和固定合同。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 运段 |
| `route` | string | 经营路径 |
| `kind` | string | 陆运或空运 |
| `currency` | string | 币种 |
| `minimum_minor` | integer | 最低承购 |
| `capacity_kg` | number | 合同计费重 |
| `transferable` | boolean | 是否可转让 |

## loads

票货按段共载；取消后最低费依旧按合同。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 装载 |
| `shipment` | string | 票货 |
| `segment` | string | 运段 |
| `kg` | number | 本段计费重 |
| `state` | string | 在载或退出 |

显式引用：`shipment` → `shipments.id`；`segment` → `segments.id`。

## charges

真实费用原币最小单位及其性质。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 账单 |
| `segment` | string | 运段 |
| `kind` | string | 固定或重量或查验 |
| `amount_minor` | integer | 原币金额 |
| `currency` | string | 币种 |
| `refundable` | boolean | 可退 |
| `known_month` | integer | 知悉月 |
| `tax_fraction` | number | 税率 |

显式引用：`segment` → `segments.id`。

## fx

实际结算汇率及费用更正。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 汇率 |
| `currency` | string | 原币 |
| `month` | integer | 结算月 |
| `cny_per_unit` | number | 每原币人民币元 |
| `known_month` | integer | 获知月 |

## agents

代理分成的有效约定。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 代理 |
| `basis` | string | 回款或核实毛利 |
| `fraction` | number | 比例 |
| `holdback` | number | 留置比例 |
| `negative_carry` | boolean | 负值结转 |

## introductions

直客归属需要核实。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 引介 |
| `shipment` | string | 票货 |
| `agent` | string | 代理 |
| `state` | string | 确认或争议 |

显式引用：`shipment` → `shipments.id`；`agent` → `agents.id`。

## prepayments

已预付代理款。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 预付 |
| `agent` | string | 代理 |
| `shipment` | string | 票货 |
| `cents` | integer | 人民币分 |
| `month` | integer | 月 |

显式引用：`agent` → `agents.id`；`shipment` → `shipments.id`。

## next_commitments

下期已卖报价和包板义务。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 承诺 |
| `segment` | string | 运段 |
| `kg` | number | 占用重 |
| `cny_cents` | integer | 确认收入 |
| `state` | string | 已卖或备选 |

显式引用：`segment` → `segments.id`。
